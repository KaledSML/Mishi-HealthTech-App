## 💡 Resumen del Proyecto

"Mishi" es un ecosistema tecnológico diseñado para mitigar el estrés académico. Utiliza un **asistente con IA** (OpenAI API) y un sistema de **misiones gamificadas** para estimular neurotransmisores del bienestar de forma natural.

### 🛠️ Especificaciones de Ingeniería
*   **Motor de Desarrollo:** Unity 3D (C#) con integración de IA.
*   **Gestión de Datos:** Backend local con **MySQL** y **XAMPP**.
*   **Estándares:** Documentación bajo **IEEE 830** y gestión basada en **PMBOK**.
*   **Metodologías:** **Lean Management**, **Kanban** y **Design Thinking**.

---

## 🧠 Filosofía de Desarrollo y Lecciones Aprendidas

El desarrollo de este proyecto se rigió bajo la **filosofía Kaizen** (mejora continua), permitiendo que la solución evolucionara desde un diseño estático hasta un prototipo inmersivo premiado.

*   **Enamorarse del Problema, no de la Solución:** La salud mental es un desafío complejo; entender el "dolor" del estudiante fue la clave para que la solución mutara de forma propositiva.
*   **Iteración con Propósito:** El paso del Prototipo v0 (Figma) al MVP funcional (Unity) demuestra que el cambio es necesario cuando se tiene al usuario final como prioridad.
*   **Resiliencia Técnica:** La integración de APIs y el desarrollo en entornos 3D requieren persistencia; aprender que el "no rendirse" es una competencia técnica tan importante como el código mismo.
