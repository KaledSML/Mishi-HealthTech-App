# 🐾 Mishi — Vitrina del proyecto

Portafolio web de una sola página para documentar **Mishi**, proyecto de titulación sobre una aplicación basada en IA y gamificación para el bienestar mental de estudiantes de educación superior.

> La web es una vitrina documental. No contiene el código fuente ni los binarios del proyecto Unity.

## ✨ Qué incluye

- Portada fantástica con ilustración CSS original y estrellas animadas.
- Secciones sobre las funcionalidades principales, demostraciones, metodología, tecnologías, validación, reconocimientos y trabajo futuro.
- Tarjetas, animaciones de entrada, menú adaptable y apartados desplegables.
- Enlaces a videos, memoria de tesis, Figma y canal de YouTube.
- Diseño adaptable a escritorio y móvil, con respeto por la preferencia del sistema de reducir movimiento.

## 🚀 Ver localmente

Abre `index.html` en un navegador moderno. No necesita instalación, compilación, servidor ni dependencias externas.

Las miniaturas de YouTube requieren conexión a internet. Todos los enlaces a YouTube, Canva y Figma se abren en sus plataformas originales.

## 🌐 Publicar con GitHub Pages

1. Crea un repositorio público destinado exclusivamente a la vitrina documental (o utiliza el repositorio que ya reservaste para ella).
2. Sube `index.html` y este `README.md` a la raíz.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama principal y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique la web y utiliza la URL que aparezca en esa sección.

No es necesario subir el proyecto Unity, binarios, claves de API ni código privado. Para mantener la vitrina simple, el sitio se construye con HTML, CSS y JavaScript en un solo archivo.

## 🔐 Alcance y propiedad intelectual

- El repositorio está pensado como documentación y portafolio, no como distribución del software.
- No incluyas claves de API, credenciales, datos de usuarios ni materiales que no tengas permiso de publicar.
- Los recursos, marcas y servicios de terceros siguen perteneciendo a sus respectivos titulares.
- Antes de publicar, revisa que los enlaces y los materiales de tesis sean accesibles públicamente y que tengas autorización para compartirlos.

## 🧭 Contenido y rigor

La web diferencia las funcionalidades descritas para el MVP, los marcos conceptuales de diseño y las ideas de trabajo futuro. No presenta la hipótesis del proyecto como eficacia clínica demostrada.
