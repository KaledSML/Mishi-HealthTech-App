## ⚙️ Ciclo de Vida y "Mutación" del Producto (Filosofía Kaizen)

El desarrollo de Mishi no fue lineal; fue un proceso de **mejora continua** donde la tecnología se adaptó a la complejidad del problema:

1.  **🎨 Fase de Ideación (Figma):** Se desarrolló un prototipo de alta fidelidad para la recolección y validación de requerimientos con el público objetivo.
2.  **🌐 Fase de Prototipado Funcional (WordPress):** La solución mutó a una plataforma web para evaluar la interacción inicial y recibir retroalimentación temprana.
3.  **🎮 Fase de Implementación Final (Unity 3D):** Tras validar el interés genuino, el proyecto evolucionó a un entorno inmersivo en 3D con **C#**, integrando **NLP** mediante la API de **OpenAI** para una experiencia personalizada.

---

## 🎮 Gamificación Científica (Framework Octalysis)
La retención del usuario se basa en el **Framework Octalysis**. Se implementaron los 8 pilares de la gamificación para estimular neuroquímicos naturales (Dopamina, Serotonina, Endorfina, Oxitocina) mediante:
*   **Significado Épico:** Misiones narrativas de autosuperación y bienestar.
*   **Desarrollo y Realización:** Sistema de misiones diarias con recompensas tangibles.
*   **Interacción IA:** Diálogo dinámico con el asistente Mishi para mitigar la ansiedad.

---

## 🛡️ Ciberseguridad, Ética y Marco Legal (NIST & RGPD)
Mishi fue diseñado bajo estrictos principios de **Seguridad por Diseño**:
*   **Marco NIST:** Se aplicaron lineamientos preventivos del **NIST Framework** para asegurar la integridad de los datos en el prototipo.
*   **Protección de Datos (RGPD):** El diseño considera el **Reglamento General de Protección de Datos (UE)** y la norma **ISO 27701**, garantizando el consentimiento informado y el tratamiento ético de la información personal.
*   **Lanzamiento Responsable:** Como medida preventiva, se omitió una versión beta abierta para evitar riesgos de exposición de datos sensibles sin supervisión clínica directa.
